01 / 协作中的透明性

Communicating Intermediate States: Multimodal Transparency in Language-Guided Human–Robot Collaboration

在线预研究 N = 31；VR 主研究 N = 32。3 × 2 被试内设计：任务理解反馈（无 / 文本 / 语音）× 视觉识别反馈（关闭 / 开启）。所有主研究条件均有实时语音转写；“无”指没有额外任务理解反馈。

  • 任务理解错误：成功取消事件的模型估计响应时间为 6.66、6.88、4.41 秒。语音相对无反馈与文本均更快（Tukey p < .001）。
  • 目标识别错误：视觉反馈关闭 / 开启时为 7.27 / 6.61 秒（p = .046）。
  • 没有证据表明反馈提高了成功取消的概率。语音条件下，每完成一项任务的总体耗时由 20.80 增至 23.15 秒；这不同于“单项成功任务时长”。
  • 注意方向由校准后的头显朝向近似，不能等同于眼动追踪。
五组核心结果与证据层级
  • 视觉反馈：目标状态感知 5.83 → 6.09（p = .035）；阶段理解与动作预测 5.72 → 6.04（p = .013）；感知安全 5.37 → 5.66（p = .013）。均为七点评分。
  • 干预响应：语音与视觉反馈分别缩短对应错误阶段的成功取消响应时间；未提高取消成功概率。
  • 注意方向：语音相较文本的工作台停留占比 44.12% vs. 40.71%（p = .025），状态屏 1.80% vs. 2.92%（p = .021）。探索性分析，N = 31。
  • 时间成本：总体每完成任务耗时 20.80 → 23.15 秒（无理解反馈 → 语音，Tukey p = .024）；单项成功任务时长不显著。
  • 采用意愿：语音＋视觉 6.09/7，均无 1.78/7。描述性排序，不声称显著优于所有组合。
未显著结果与探索性组合效应

任务理解反馈对九个主观维度均无显著主效应。视觉反馈对干预准备、信息有用性、信息负担、工作负荷和协作满意度无显著主效应。完成数、超时数、错误装配数、单项成功任务时长及取消成功概率未发现显著反馈效应。未显著不等于证明等效。

所有主观维度和题项均未发现显著交互。部分条件内比较显著，例如已有语音时增加视觉反馈，心理需求 3.01 → 3.62（p = .021）；没有理解反馈时增加视觉反馈，信息有用性 4.91 → 5.37（p = .035），信息负担 5.34 → 5.88（p = .034）。这些仅作探索性线索，不能解释为已经证明协同、补偿或必然过载。

理解反馈对当前阶段理解单题 Q4 的总体检验 p = .048，但 Tukey 两两比较不显著。可靠性 Q8 总体检验 p = .057；语音与无反馈的两两比较 p = .047，论文仅作探索性解释。

预研究、系统体验与分析边界

预研究 N = 31：包含任务理解信息的方案比仅语音转写或无反馈具有更高的感知透明性；仅任务理解与其加语音转写没有显著差异。目标框平均偏好排名最好，但三种视觉叠加方案之间的透明性没有显著差异。

系统有用性 6.00/7，继续使用意愿 6.16/7，整体信任 5.16/7，感知安全 4.94/7；SUS 69.38/100。临场感均值 0.43（量表 −3 至 +3）；SSQ 由实验前 2.81 升至 11.10（Holm p = .020），存在 VR 不适成本。这些是整体评估，不能作为某一反馈条件的因果效果。

部分两两检验使用 Tukey 或 Holm 校正；未对所有结果指标统一进行多重比较校正。注意分析为探索性；受控 VR 结果不能直接推广为真实机械臂的物理安全或长期使用效果。区间与 SD 均按各自定义报告，不互相替代。

来源：chi27a-sub6799-i13.pdf · §4–5，pp. 8–19；局限见 §7，p. 21。

02 / 家庭中的任务委托

Handing Off Without Losing Track: User-Robot Communication in Multi-Stage Household Task Delegation

N = 32。阶段一比较指令粒度与执行前计划披露；阶段二在 VR 中比较四种进度反馈策略。两组参与者分别观看纪录片或校对文本，每组 16 人。

  • 30/32 人在总体偏好中选择了带有计划披露的委托方式。这是偏好分布，不是任务成功率。
  • 主动反馈的三种策略在感知适切性、任务状态理解和表现信任上均优于无主动反馈；按阶段反馈优于仅在转向机器人时触发的反馈。
  • 30/32 人希望在异常、暂停或不确定时增加反馈；26/32 人希望在高度专注时减少反馈。来自实验后的多选问卷，未直接验证完整的自适应系统。
  • 本页即时交互为改编演示：每次转向立即触发，朝向时立即停止语音。原研究的转向触发策略设有至少 5 秒间隔与同阶段去重；抑制策略按阶段变化时的朝向决定是否播报，已经开始的语句会继续说完。
  • 四种策略采用头部朝向信号；VR 任务为脚本化的成功执行，尚不能推广为真实家庭中的长期效果。

来源：家庭机器人.pdf · Table 1，p. 8；§4.1–4.4，pp. 11–18；局限见 §6，p. 21。
